SECURITY & TRUST

Your memories are
yours.

Legacy Lens is being designed around privacy, security and user control.

Encryption

Protect personal information and stored memories with encryption when the backend is implemented.

Strong Authentication

Support secure authentication methods such as strong passwords, two-factor authentication and passkeys.

Private By Default

Personal memories should not automatically become public.

User Control

Users decide what they preserve, share and eventually pass on.

Secure Originals

Original memories should remain separate from enhanced or AI-generated versions.

Account Security

Login alerts, secure sessions, recovery controls and suspicious activity protection.

Security architecture designed for the future platform.
